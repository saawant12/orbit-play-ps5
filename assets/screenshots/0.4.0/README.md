These interface previews show the screens that changed in Orbit Play **0.4.0**,
with example data. **Player One** is a fictional profile: use the one shown on
your own PS5. The images illustrate settings, not a live game stream. Screens
that didn't change are in the [0.2.0-beta.1 screenshots](../0.2.0-beta.1/README.md).
