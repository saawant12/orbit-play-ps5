# Orbit Play 0.2.0-beta.1

[Project README](../README.md) · [Screenshot walkthrough](../guides/getting-started.md) · [Installation](../guides/installation.md)

Orbit Play is a Remote Play app for jailbroken PS5s, available on Mac, Windows
and Linux. It is an alternative to Sony's PS Remote Play app for playing over
your local network without PSN sign-in or an internet connection. It can enable
Remote Play for local PS5 accounts that have never been linked to PSN, creating
a local account ID after your confirmation when needed. The streaming player
and matching PS5 helper are included.

**No PSN sign-in in Orbit Play. No manual account-ID lookup or conversion. No
separate Remote Play PIN generator or Chiaki app.** Run the helper on your
jailbroken PS5, enter its address and six-digit trust code, then pair and play.
Orbit Play handles the Remote Play PIN automatically.

**This beta connects over your local network only.** Keep the computer and PS5
on the same trusted network, with the console awake and the intended user logged in.

## What's included

- Local pairing using the helper's six-digit trust code.
- Separate saved pairings for each console address and PS5 profile.
- H.264 video at 360p, 540p, 720p or 1080p, with 30 or 60 fps and 1–50 Mbps.
- DualSense controls over USB or Bluetooth, plus keyboard and mouse-button controls.
- Up to three automatic reconnect attempts after a network interruption.
- Account setup when a profile needs a local ID or Remote Play enabled, with
  reviewed changes and account-settings backups.
- Diagnostic exports that omit addresses, names, account IDs, PINs and pairing keys.

**Account setup is experimental. We recommend a separate new PS5 profile with no
saves.** Creating a local ID may make existing saves inaccessible and requires
your confirmation. Backups cover account settings,
not games or saves. Recovery keeps an assigned ID to protect newer saves. Read
[account setup and recovery](../guides/account-setup.md) before using it.

## Compatibility

You need a jailbroken PS5 and a payload loader to run the helper. This beta has
been tested on **PS5 firmware 13.60 with Relapse and Payload Manager v0.5.2**, using
Apple Silicon Macs, Windows x64, and Linux x64 and arm64 computers.

Testing covers pairing, video and audio, keyboard and USB/Bluetooth DualSense
controls, reconnecting, helper restarts, profile switching, picture settings,
and setup and recovery with a new profile.

On 13.60, you can pair after initial account setup without restarting the PS5.
Other firmware may work but is untested; restart the PS5 after account setup,
then reload the jailbreak and helper before pairing. After restoring account
settings, follow the restart instruction on any firmware.

## First launch

- **Mac:** open the DMG and drag Orbit Play to Applications. This beta is not
  Apple-notarized. If macOS blocks a download you trust, open
  **System Settings → Privacy & Security → Open Anyway**, then confirm **Open**.
- **Windows:** extract the whole ZIP and open `OrbitPlay.exe`. The app is not
  code-signed. If SmartScreen warns about a download you trust, choose
  **More info → Run anyway**. Allow Orbit Play on private networks if Windows
  Firewall asks.
- **Linux:** make the AppImage executable with `chmod +x`, then run it. If FUSE
  is unavailable, use `--appimage-extract-and-run`.

Follow the [installation guide](../guides/installation.md) and
[screenshot walkthrough](../guides/getting-started.md) for the complete steps.

## Fixes

- Fixed an unexpected player exit shortly after connecting a DualSense.
- Controller buttons now release if the controller stops responding.
- Stopping a stream closes the player immediately.
- The console address stays in place while you type on the Find screen.
- Account setup and recovery are blocked while a stream is open.
- Automatic reconnect can retry when a network drop briefly makes the helper unreachable.

## Unavailable in this beta

Internet remote access, wake from Rest Mode, HDR, microphone, haptics, PS5
login-passcode prompts, Intel Macs and account migration are not supported.
