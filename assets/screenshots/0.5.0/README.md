# Orbit Play 0.5.0 screenshots

These interface previews show Orbit Play **0.5.0** with example data. **Player
One** is a fictional profile, and the connection details are examples. The
images illustrate setup, not a live game stream. Screens that look the same as
in earlier versions link to those images.

For instructions beside each screenshot, follow the
[getting-started guide](../../../guides/getting-started.md),
[playback and controls](../../../guides/playback-and-controls.md) and
[play away from home](../../../guides/play-away-from-home.md).
