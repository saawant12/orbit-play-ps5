# Orbit Play screenshot guide

These interface previews show Orbit Play **0.2.0-beta.1** with example data.
**Player One**, **192.0.2.10** and **123456** are fictional: use the profile,
address and trust code shown on your own PS5. The images illustrate setup and
settings, not a live game stream.

For instructions beside each screenshot, follow the
[getting-started guide](../../../guides/getting-started.md).
