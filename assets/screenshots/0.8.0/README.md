# Orbit Play 0.8.0 screenshots

These interface previews show Orbit Play **0.8.0** with example data. **Player
One** is a fictional profile; the console names, addresses and games are
examples. The mini player and player bar images show a stream of the PS5's own
Settings screen, not a game. Screens that look the same as in earlier versions
link to those images.

For instructions beside each screenshot, follow the
[getting-started guide](../../../guides/getting-started.md),
[playback and controls](../../../guides/playback-and-controls.md),
[play away from home](../../../guides/play-away-from-home.md) and
[control the player from other apps](../../../guides/player-control.md).
