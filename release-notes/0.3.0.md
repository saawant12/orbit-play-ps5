# Orbit Play 0.3.0 (Beta)

[Project README](../README.md) · [Getting started](../guides/getting-started.md) · [Installation](../guides/installation.md)

**0.3.0 is prepared for release and is not yet published.** The current download is [0.2.0-beta.1](https://github.com/saawant12/orbit-play-ps5/releases/tag/v0.2.0-beta.1).

## Start the PS5 helper from Orbit Play

You can now send and start the included PS5 helper directly from the computer app. Load your jailbreak, open Payload Manager or enable an ELF loader, then enter the PS5's IP address in **Console setup** and choose **Start helper on PS5**. Enter the six-digit trust code shown on your PS5, then pair and play. No separate ELF download is needed.

- Uses Payload Manager first, with an ELF-loader fallback when Payload Manager is unavailable.
- Lets you change the loader ports under **Profile & connection options**, and remembers them once the helper responds.
- Checks for an existing helper before sending one. If a different version is running, it asks you to stop that instance first.
- Checks whether the helper started when a launch response is lost, without sending a second launch.
- Keeps **Get PS5 helper** and **Find console** available if you prefer to run the helper yourself.

## Updating from 0.2.0-beta.1

Stop your stream and quit the old computer app. Install 0.3.0, then stop the old Orbit Play helper in Payload Manager. Replacing an ELF file does not stop its running process. If you cannot stop it, fully restart the PS5 and reload the jailbreak.

In the new app, open **Console setup → Start helper on PS5** and enter the new trust code. Your saved pairings and playback settings are kept. The computer app and PS5 helper must both be version **0.3.0**.

## Compatibility and limits

Orbit Play connects over your local network without PSN sign-in. Keep the PS5 awake and logged into the intended profile. Supported computer builds are Apple Silicon Mac (macOS 26+), Windows x64 (including Windows 11 on ARM through x64 emulation), and Linux x64/arm64 (Ubuntu 24.04 or compatible).

The installed 0.3.0 Mac app has been tested with the PS5. The tested console setup is **PS5 firmware 13.60 with Relapse and Payload Manager v0.5.2**. Windows and Linux gameplay were tested with the previous beta; those platforms and the raw ELF-loader fallback have not been separately revalidated on hardware for 0.3.0. Other PS5 firmware remains untested.

**Account setup is experimental. We recommend a separate new PS5 profile with no saves.** Creating a local account ID may make existing saves inaccessible and requires your confirmation. Existing account IDs are kept. Account-settings backups do not contain games or saves. Read [account setup and recovery](../guides/account-setup.md) before continuing.

Internet remote access, wake from Rest Mode, HDR, microphone, haptics, PS5 login-passcode prompts, Intel Macs and account migration remain unavailable. Wake from Rest Mode, HDR, microphone input and haptics are in development.

Mac builds are not Apple-notarized and Windows builds are not code-signed. Follow the [installation guide](../guides/installation.md) for first-launch approval.
