# Orbit Play 0.4.0 screenshots

These interface previews show Orbit Play **0.4.0** with example data. **Player
One** is a fictional profile and **123456** a fictional trust code: use the
profile and code shown on your own PS5. The images illustrate setup and
settings, not a live game stream. Screens that look the same as in 0.2.0-beta.1
link to those images.

For instructions beside each screenshot, follow the
[getting-started guide](../../../guides/getting-started.md) and
[playback and controls](../../../guides/playback-and-controls.md).
